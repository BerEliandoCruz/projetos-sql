# 🗄️ Projetos SQL

Repositório dedicado aos meus estudos e projetos acadêmicos de **Banco de Dados**, desenvolvidos durante o curso técnico integrado ao Ensino Médio em Desenvolvimento de Sistemas.

Aqui estão reunidos modelos de bancos de dados, relacionamentos entre tabelas e scripts SQL desenvolvidos para praticar modelagem e manipulação de dados.

## 📚 Projetos

### 1. Professor e Cursos

Modelo de banco de dados para organizar informações de professores e cursos.

**Principais tabelas:**
- `professor`
- `Curso`

**Conceitos utilizados:**
- Criação de tabelas;
- Chaves primárias (PRIMARY KEY);
- Chaves estrangeiras (FOREIGN KEY);
- Relacionamento entre tabelas.

### 2. Gestão de Funcionários e Obras

Modelo de banco de dados voltado ao gerenciamento de funcionários, cargos, cursos, obras, atividades, materiais e fornecedores.

**Principais tabelas:**
- `empregado`
- `cargo`
- `Orgão`
- `planoCarreira`
- `titulação`
- `cursos`
- `obra`
- `atividade`
- `material`
- `fornecedor`

**Conceitos utilizados:**
- Modelagem de dados;
- Relacionamentos entre múltiplas tabelas;
- Chaves primárias e estrangeiras;
- Tabelas associativas;
- Organização de dados relacionados.

## 🛠️ Tecnologias e ferramentas

- **MySQL** — criação e gerenciamento de bancos de dados;
- **SQL** — linguagem para definição e manipulação de dados;
- **DBDesigner** — modelagem de bancos de dados;
- **Git e GitHub** — versionamento e organização dos projetos.
